# Quality Inspection Tracker

## Tech Stack

- React
- Material UI
- Node.js
- Express
- PostgreSQL
- React Hook Form
- Zod

## Features

- Dashboard Summary
- Add Inspection
- Resolve Inspection
- Filter by Status
- Filter by Severity
- Search by Machine ID

## Installation

Backend

npm install
npm run dev

Frontend

npm install
npm run dev

Database

Run inspection.sql
